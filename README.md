# Band-Name-Generator
This is a simple program that generates a band name based on user input. 
## The program asks the user for:
- The city they grew up in
- The name of a childhood pet

The program then combines these inputs to suggest a band name.

## What I learnt:
- Getting input from users using "input()"
- Storing user input in variables
- Combining strings to create an output (String Concatenation)
- Writing code that interacts with users
- Writing clear and readable code
